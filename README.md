# UrbanServe

UrbanServe is a smart public parking management system designed to make parking operations more efficient. Users can view parking availability, book slots, manage bookings, and receive notifications, while operators can monitor parking usage, bookings, slot availability, and maintenance activities.

### Live Dashboards

- **User Dashboard:** https://urbanserve-sigma.vercel.app
- **Operator Dashboard:** https://urbanserve-sigma.vercel.app/operator.html
